A modern real-time chat application that enables seamless communication with instant messaging, secure authentication, and media sharing.

Built using Firebase for authentication & database and Supabase for media storage, this app delivers a fast and scalable chat experience.

🚀 Features
🔴 Real-time messaging (instant updates)
🔐 Secure user authentication (Firebase Auth)
💬 One-to-one chat system
🟢 Online/offline user presence
🖼️ Image/media sharing via Supabase
📡 Live database sync using Firebase


🛠️ Tech Stack
Frontend
    React.js
   
Backend / Services
    Firebase Authentication
    Firebase Firestore (Real-time Database)
    Supabase Storage (Media handling)
    

🔄 How It Works
Users sign up/login via Firebase Authentication
Chat data is stored and synced in Firestore
Real-time updates are pushed automatically to all users
Media files are uploaded to Supabase Storage
Media URLs are stored in Firestore and rendered in chat
