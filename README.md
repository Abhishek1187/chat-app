# 💬 Real-Time Chat Application

A modern real-time chat application that enables seamless communication with instant messaging, secure authentication, and media sharing.

Built using **Firebase (authentication & database)** and **Supabase (media storage)**, this app delivers a fast and scalable chat experience.

---

## 🚀 Features

- 🔴 Real-time messaging (instant updates)
- 🔐 Secure user authentication (Firebase Auth)
- 💬 One-to-one chat system
- 🟢 Online/offline user presence
- 🖼️ Image/media sharing via Supabase
- 📡 Live database sync using Firebase

---

## 🛠️ Tech Stack

### Frontend
- React.js

### Backend / Services
- Firebase Authentication
- Firebase Firestore (Real-time Database)
- Supabase Storage (Media handling)

---

## 🔄 How It Works

1. Users sign up/login via Firebase Authentication  
2. Chat data is stored and synced in Firestore  
3. Real-time updates are pushed automatically to all users  
4. Media files are uploaded to Supabase Storage  
5. Media URLs are stored in Firestore and rendered in chat
